Virtual Piano Arranger

Офлайн-пианино, буквенная запись и импорт выбранных партий MIDI. Распознавание нот экспериментальное.

Предварительная версия · 0.1.0-preview.1 Windows · x64
Скачать для Windows Играть в браузере → Исходный код Python · PySide6 Руководство ↗

Перед запускомWindows x64; Python/Qt и отдельный runtime распознавания включены. EXE без цифровой подписи.

Что внутри

Установка, функции, передача данных и проверка.

Установка

Шаги из раздела «Начало работы» README и описания выпуска.

1. Скачать portable ZIP из GitHub Releases, сверить SHA-256 с SHA256SUMS.txt
2. Распаковать всю папку portable
EXE нельзя переносить отдельно от остальных файлов; Python и права администратора не нужны
3. Запустить VirtualPianoArranger.exe (EXE без цифровой подписи)
4. Открыть MIDI, прослушать партии и импортировать нужные

Ваши данные

Программа для Windows работает офлайн на вашем ПК. Страница с пианино в браузере никуда не отправляет ноты и файлы; аналитики и cookie нет.

Проверено

  • Тесты в репозитории: Python-тесты (test_*.py) и тесты браузерной версии (web/tests, Node.js)
  • Контрольная сумма SHA-256 (SHA256SUMS.txt) и соответствующие исходники в выпуске
  • Уведомления о лицензиях и происхождении (THIRD_PARTY_NOTICES, MODEL_PROVENANCE)
  • Руководство на немецком, английском и русском
  • Предварительная версия 0.1.0-preview.1: точность распознавания, другие ПК и длинные сеансы ещё не проверены полностью
