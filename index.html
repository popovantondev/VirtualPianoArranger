Was drin steckt

Installation, Funktionen, Datenverbindung und Prüfung.

Installation

Die Schritte aus „Erste Schritte“ im README und in der Release-Beschreibung.

1. Portable-ZIP aus GitHub Releases laden, SHA-256 mit SHA256SUMS.txt vergleichen
2. Den gesamten Portable-Ordner entpacken
Die EXE nicht von ihren Begleitdateien trennen; Python und Administratorrechte sind nicht nötig
3. VirtualPianoArranger.exe starten (die EXE ist nicht digital signiert)
4. MIDI-Datei öffnen, Stimmen anhören und importieren

Ihre Daten

Das Windows-Programm arbeitet offline auf Ihrem PC. Die Klavierseite im Browser sendet Noten und Dateien nirgendwohin; es gibt weder Analyse noch Cookies.
