Installation

The steps from “First steps” in the README and the release description.

1. Download the portable ZIP from GitHub Releases, compare SHA-256 with SHA256SUMS.txt
2. Extract the entire portable folder
Keep the EXE beside its companion files; no Python or administrator access needed
3. Start VirtualPianoArranger.exe (the EXE is not digitally signed)
4. Open a MIDI file, audition the parts and import them

Your data

The Windows program works offline on your PC. The piano page in the browser sends notes and files nowhere; there is no analytics and no cookies.

Runs locally
